Import Concert CSV

Expected CSV Format & Column Order

Your CSV file should have a header row with the following column structure:

Col 1: Date MM/DD/YYYY or YYYY-MM-DD
Col 2: Artist(s) Comma-separated list
Col 3: Venue Venue / Arena name
Delineating Multiple Bands: Separate multiple artists with commas. The first band is designated as the primary headliner, followed by supporting acts. In CSV files, enclose multiple artists in quotes.
# Example row:
10/24/2023, "Foo Fighters, The Breeders", Madison Square Garden
